## 🌟 Overview

**Turbo Bike Mode** is a high-performance, standalone Android application that brings **intelligent riding mode** to all Android smartphones (OnePlus, Xiaomi, Motorola, Samsung, Vivo, Oppo, Google Pixel, Realme, and others) without requiring OEM locks, special hardware widgets, or proprietary firmware.

It solves the dangerous problem of distracted riding by keeping your phone **100% silent**, providing automatic **switched-off simulation** and **bilingual auto-reply SMS**, while guaranteeing that **genuine life-threatening emergencies can still break through** via an intelligent 3-call detection protocol.

---

## 🚀 Key Features

| Feature | Description |
| :--- | :--- |
| 🔇 **100% True Silent Ride** | Complete phone silence while riding. Zero speaker bleed, no wind noise in Bluetooth helmet earbuds, and zero distraction. |
| 📞 **Custom Number Divert** | Enter and save any dummy, unallocated, or spare switched-off number to trigger carrier announcements (*"Switched off"* or *"Not in service"*). |
| 🌐 **Internet Stays 100% Active** | 4G/5G mobile data, GPS navigation (Google Maps), and messaging apps (WhatsApp) remain fully functional during the ride. |
| 💬 **Dual-Language Auto-SMS** | Dispatches an instant bilingual (English & Hindi) emergency auto-reply SMS to callers within 1.5 seconds of call termination. |
| 🚨 **3-Call Emergency Breakthrough** | If a caller dials **3 times within 5 minutes**, the call is recognized as an emergency! Silent mode is overridden at **MAX volume** with a siren. |
| 📋 **Ride Call Summary** | Once Bike Mode is toggled OFF, a clean summary appears showing all missed callers with one-tap callback buttons. |
| 🔒 **100% Offline & Private** | Zero external cloud servers, zero APIs, and zero data leakage. All logic runs strictly on-device. |

                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
   Calls 1 & 2                      Call 3 (Within 5m)
         │                                 │
         ▼                                 ▼
  Call Disconnected              🚨 EMERGENCY BREAKTHROUGH!
(Carrier Switched-Off Prompt)    - Overrides silent mode
         │                       - Rings at MAX volume with siren
         ▼                       - Shows contact name (Mom, Dad, etc.)
  Instant Auto-SMS sent          - Rider pulls over to answer safely
(Bilingual: English + Hindi)
`

## 📥 Installation Guide

1. **Download the APK**: Click **[TurboBike.apk](TurboBike.apk)** directly from this repository (or from the download badge above).
2. **Install**: Tap the .apk file on your device and select **Install**.
3. **Grant Permissions (Android 13 / 14)**:
   - Go to phone **Settings &rarr; Apps &rarr; Turbo Bike Mode**.
   - Tap the **3 dots (⋮)** in the top-right corner &rarr; **Allow restricted settings**.
   - Enable **Phone**, **SMS**, and **Contacts** permissions.
